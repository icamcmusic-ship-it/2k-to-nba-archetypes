BBGM → NBA 2K Archetype Converter

Translate Basketball GM ratings (1–100, 50 ≈ NBA average) into their closest NBA 2K build archetypes. Ratings are mapped through player percentiles, then matched against 1,256 2K builds in percentile space — builds demanding skills the player doesn't have are penalized, and builds whose shape doesn't look like the player are penalized too.

Settings

"This league" derives percentile anchors from the roster you upload, so a weaker/stronger/historical league is graded against itself instead of against the modern NBA. The height scale is BBGM's default (0 ≈ 5'6", 50 ≈ 6'6", 100 ≈ 7'6") — leagues can customise it.

Badge legend

Badge levels shown for the single-player calculator are derived from the converted 2K ratings and height, using each badge's real attribute thresholds and height range (). Badges with alternative requirements (e.g. Deadeye: Midrange or 3PT) use the player's best qualifying attribute; badges that genuinely need multiple skills (e.g. Posterizer: Driving Dunk and Vertical) are capped at the lowest tier reached across them. Badges whose height requirement the player doesn't meet show as unavailable. The badge-point total approximates 2K's own tier cost budget (Bronze 2 → Legend 16), so two builds can be compared by how much badge economy they actually unlock rather than by a raw badge count.

Methodology

1. BBGM → percentile. Each rating becomes a percentile within a reference distribution — the modern NBA by default, or the uploaded roster itself in "this league" mode. An exponential curve stretches both the top and bottom 10% so elite (and truly poor) ratings stay elite (or poor) after translation.

2. Percentile → 2K rating. The percentile maps onto 2K's own rating distribution for that stat. Each 2K stat blends the BBGM inputs that actually drive it rather than copying one: Interior Defense is dIQ + Strength + height, Block is dIQ + Jmp + height, Driving Dunk is Dnk + Jmp + Spd, Defensive Rebound is Reb + height, and so on. Height feeds ratings here, not just the build filter, so a 7'2" and a 6'2" player with identical dIQ no longer convert to identical rim protection. Endu isn't modeled by any 2K attribute — it's shown as a separate conditioning note instead of being silently ignored.

3. Matching. Both the player and every build's min/max range are expressed in percentiles, so a point means the same thing in every stat and the declared per-stat weights actually control influence. A player inside a build's range costs nothing; falling short of a minimum is penalized quadratically; exceeding a maximum costs a third as much. On top of that, a shape term penalizes builds whose strength/weakness pattern doesn't look like the player's — without it only deficits bind, so the cheapest builds in the database win for everybody. Any build demanding a skill 40+ percentile points beyond the player is disqualified. Builds whose height range doesn't fit (±1") are excluded, relaxing to nearest-height builds rather than the whole database.

3b. Key attributes. Every build has key attributes: the stats it demands at the 70th percentile or better — the ones it's actually built around (capped at its five most demanding). Falling more than 15 percentile points short of any of them disqualifies the build outright, including in the fallback. Without that last part the veto did nothing: it refused the build, and the cascade underneath handed the player the same build anyway. Each match shows what it's built around and exactly how far short the player is, and a build whose key attribute the player misses can never grade better than "Loose fit". When nothing qualifies, that's reported as its own outcome — the closest shapes are still listed, as "what he'd be if he developed", not "what he is". On a typical BBGM league roughly half the players qualify for no build at all; that's an honest fact about the league, since 2K's database describes MyPlayer creations with elite attributes and a rotation player isn't one.

4. Fit grade. The headline number is a calibrated grade derived from the raw penalty (Excellent / Good / Loose / Poor / No real build). Cut points are per mode — the same penalty means different things graded against the NBA and against a weaker league, and one shared table put three quarters of a league at "Good fit" or better in league mode — and when a whole roster is loaded the grade is a percentile against that roster's own penalty distribution instead. A build the player misses a key attribute on is capped at "Loose fit" whatever its penalty. The build's rank within the eligible pool is still shown, as a secondary line.

5. Badges. Converted ratings and height run through 2K's real badge thresholds (), Bronze → Legend, gated by each badge's height range.

Known limitations
  • The build database is shooting-first: 73% of the 1,256 builds require a 3PT rating of 80+, so shooting archetypes are common even with a perfectly calibrated matcher. Use the archetype browser's "max 3PT requirement" filter to see the rest.
  • 59% of the database's stat entries have min = max; those are widened by ±2 before matching so they aren't dramatically harsher than genuinely banded stats.
  • Free Throw drives no 2K badge, so its conversion only affects archetype matching.
  • Wingspan and weight/body type aren't modeled — BBGM has no equivalent input, and Strength is only a rough proxy for the latter.
  • Badge thresholds come from a single game version; 2K changes them year to year. Badge earn rates are also uneven across categories (Shooting is the cheapest), and 14 of 40 badges still can't reach Legend because their Legend thresholds sit above the top of their stat's anchor curve.
  • Reverse mode (build → BBGM ratings) is a least-squares inverse, but 21 2K stats are built from 15 BBGM ones, so builds that pull shared inputs in opposite directions (high Block, low Interior Defense) aren't representable at all. Feeding a build's own profile back in recovers it into the top 3 about half the time; a perfect nearest-profile oracle manages ~60%, so the rest is information loss in the ratings model, not a matching error. Endurance has no 2K source and is filled in at league average.
