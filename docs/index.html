Methodology

Each BBGM rating is converted to an NBA percentile using the distribution of all current NBA players, then that percentile is converted to the equivalent NBA 2K rating using 2K's own rating distribution. An exponential curve stretches the top 10% so elite ratings translate to truly elite 2K values.

BBGM stats fan out to 2K stats: Ins → Close Shot / Driving Layup / Post Control; Dnk → Driving / Standing Dunk; Drb → Ball Handle / Speed With Ball; dIQ → Interior D / Perimeter D / Steal / Block; Reb → both rebounds; Spd → Speed / Agility; Stre → Strength; Jmp → Vertical; Mid, 3Pt, FT and Pss map directly. Height converts to inches (BBGM 0 ≈ 5'6", 50 ≈ 6'6", 100 ≈ 7'6").

The converted 2K profile is compared to every build's rating ranges (midpoints) with weighted cosine similarity — physicals and primary scoring weigh more, and any stat at or above the 85th NBA percentile gets a 1.5× "signature skill" boost. Builds whose height range doesn't fit the player (±1") are excluded; the filter relaxes automatically if nothing fits.
