Badge legend

Badge levels shown for the single-player calculator are derived from the converted 2K ratings and height, using each badge's real attribute thresholds and height range. Badges with alternative requirements (e.g. Deadeye: Midrange or 3PT) use the player's best qualifying attribute; badges that genuinely need multiple skills (e.g. Posterizer: Driving Dunk and Vertical) are capped at the lowest tier reached across them. Badges whose height requirement the player doesn't meet show as unavailable.

Methodology

Each BBGM rating is converted to an NBA percentile using the distribution of all current NBA players, then that percentile is converted to the equivalent NBA 2K rating using 2K's own rating distribution. An exponential curve stretches the top 10% so elite ratings translate to truly elite 2K values.

BBGM stats fan out to 2K stats: Ins → Close Shot / Driving Layup / Post Control; Dnk → Driving / Standing Dunk; Drb → Ball Handle / Speed With Ball; dIQ → Interior D / Perimeter D / Steal / Block; Reb → both rebounds; Spd → Speed / Agility; Stre → Strength; Jmp → Vertical; Mid, 3Pt, FT and Pss map directly. Height converts to inches (BBGM 0 ≈ 5'6", 50 ≈ 6'6", 100 ≈ 7'6").

The converted 2K profile is compared to every build's rating ranges (midpoints) with an asymmetric weighted fit score: every point a build demands above what the player has counts as a full-weight skill deficit, while exceeding a build's needs costs only a third as much. Physicals and primary scoring weigh more, and any stat at or above the 85th NBA percentile gets a 1.5× "signature skill" boost so builds that don't feature the player's elite skills rank lower. Builds whose height range doesn't fit the player (±1") are excluded — the filter relaxes automatically if nothing fits — and any remaining height mismatch is penalized per inch. Each match card lists the build's biggest remaining skill gaps so you can see where the player falls short.
