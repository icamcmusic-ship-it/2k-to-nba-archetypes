Badge legend

Badge levels shown for the single-player calculator are derived from the converted 2K ratings and height, using each badge's real attribute thresholds and height range. Badges with alternative requirements (e.g. Deadeye: Midrange or 3PT) use the player's best qualifying attribute; badges that genuinely need multiple skills (e.g. Posterizer: Driving Dunk and Vertical) are capped at the lowest tier reached across them. Badges whose height requirement the player doesn't meet show as unavailable, and height is clamped into the badges' supported 5'9"–7'4" band first so a very tall player doesn't lose every badge at once.

Why so many badges are common. A typical player earns roughly half the catalogue, and some badges are earned by over 90% of a league. That isn't a threshold bug: 2K's rating scale is compressed at the top — the NBA median Close Shot is 80 — so most real NBA players genuinely do clear the Bronze bar on the low-requirement badges. Rather than invent harsher thresholds that would no longer match 2K, each badge shows its league-wide earn rate and the badge-points total is rarity-weighted, so a badge 90% of the league has counts for far less than one only 10% earn. That total, not the raw count, is the number that describes a player's trait identity.

Coverage. The catalogue is hand-authored — the source workbook contains no badge data to generate it from — and mirrors the 2K25 list: 42 badges across Shooting (6), Playmaking (10), Finishing (11), Defense (10), Rebounding (2) and General (3). Rebounding genuinely has only two badges in 2K, and 2K models no Free Throw badge at all, so Free Throw influences archetype matching but earns nothing here. Multi-attribute badges can cap below Legend through one path (Unpluckable caps at Gold via Post Control); the table explains that where it applies, and shows how many points a near-miss is from the next tier.

Methodology

Each BBGM rating is converted to an NBA percentile using the distribution of all current NBA players, then that percentile is converted to the equivalent NBA 2K rating using 2K's own rating distribution. An exponential curve stretches both the top and bottom 10% so elite (and truly poor) ratings translate to truly elite (or poor) 2K values instead of bunching up near the middle.

Every 2K stat blends several BBGM inputs rather than reading one. That matters: when Close Shot, Driving Layup and Post Control all read Ins alone they are monotone transforms of one number, so they move in perfect lockstep and the tool literally cannot represent a slasher who can't post up, a lob threat who can't dunk off two feet, or a perimeter stopper who can't protect the rim. Each stat keeps a dominant primary input plus the physical and mental inputs that separate it — note the deliberately opposed pairs: Driving Dunk leans on Dnk + Spd/Jmp while Standing Dunk leans on Dnk + Hgt/Stre; Perimeter D leans on dIQ + Spd while Interior D leans on dIQ + Hgt/Stre. Steal draws on dIQ + oIQ + Spd, Block on dIQ + Jmp + Hgt. Endu isn't modeled by any 2K attribute — it's shown as a separate conditioning note instead of being silently ignored. Height converts to inches using the workbook's own reference table (BBGM 0 ≈ 5'6", 50 ≈ 6'6"), and a plausible playing weight is derived from height and strength to match against each build's weight range.

On top of that, each stat gets a small deterministic offset seeded from the player's own rating vector. It's stable — the same player always converts to exactly the same numbers, and a shared link reproduces the result precisely — but it stops two different players from being perfectly colinear, which is what otherwise makes hundreds of builds score identically. You can turn it off under "Stat decorrelation".

The converted 2K profile is compared to every build's actual rating range (not a midpoint) with an asymmetric weighted fit score: a player sitting inside a build's range costs nothing; every point a build's minimum exceeds what the player has counts as a skill deficit that scales quadratically (one glaring hole sinks a build rather than averaging away), while exceeding a build's maximum costs only a third as much. Any build demanding a skill 22+ points beyond the player is disqualified outright (relaxed only if too few builds survive). Physicals and primary scoring weigh more, and any stat at/above the 85th or at/below the 15th NBA percentile gets a 1.5× boost — builds must feature the player's elite skills and avoid demanding the ones he clearly lacks. Builds whose height range doesn't fit the player (±1") are excluded — the filter relaxes automatically if nothing fits, and height itself is clamped to the archetype database's supported range (roughly 5'9"–7'4") before matching, with a note shown when that clamp kicks in. Any remaining height mismatch within the pool is penalized per inch. The displayed "% fit" is the match's percentile rank against every other build reachable for this player — not an absolute quality score — so it stays informative even for below-average or maxed-out inputs. Each match card lists the build's biggest remaining skill gaps as targets ("Steal 60 → needs 75"), labels whether the shortfall is cosmetic or structural, and breaks down which stats actually drove the penalty.

Distinctiveness and variety. A build whose ranges are so wide that almost anyone sits inside them scores a perfect zero penalty while telling you nothing — left unchecked, those catch-all builds win for every player and a whole league collapses onto a handful of names. Each build is therefore charged for its own looseness, so among the builds a player genuinely fits, the most specific one wins. In batch mode a "Roster variety" setting additionally applies a soft penalty to builds already assigned many times: off reproduces pure best-fit, higher settings trade a little per-player fit for a roster that actually differentiates its players. Over the bundled 974-player league this takes the most common archetype from 20.4% of the league down to 8.5% (best-fit) or 3.7% (variety on), with distinct top matches rising from 45 to 173 / 312.
